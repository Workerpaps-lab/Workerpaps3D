# Workerpaps3D

Este repositorio contiene herramientas para generar modelos 3D utilizando inteligencia artificial. Ofrecemos integración con herramientas populares como Blender y Roblox para facilitar la generación de contenido 3D a partir de modelos generadores de inteligencia artificial.

## Cómo comenzar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Workerpaps-lab/Workerpaps3D.git
   cd Workerpaps3D
   ```
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Prueba el script de ejemplo para generar un modelo 3D:
   ```bash
   python src/generate_basic_shape.py "cubo"
   ```
